This Flutter project serves as learning Dart and Flutter for me. It is developed as part of studying project at my university.

Krakflow is a standard task manager app, where you can store your tasks, create new ones (with properties such as deadline, priority, etc.).

This is small project and like said above, its main purpose is to learn Flutter ;) 
This app covers basics of Navigation in Flutter, REST API, local databases (such as SQLite, Hive, Drift), basic UI/UX skill training, Firebase, Notifications.
